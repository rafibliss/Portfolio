# Rafi's Portfolio
Next.js (App Router) + TypeScript + Tailwind CSS v4.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Edit your content in `lib/data.ts`. Replace `public/rafi.jpg`, `public/resume.pdf`, and `public/projects/*.svg` with your own files.
Deploy: push to GitHub and import on Vercel (zero config).
