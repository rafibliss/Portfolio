# AGENTS.md

Single-page developer portfolio. Next.js 16 (App Router, Turbopack default) + React 19 + TypeScript strict + Tailwind CSS v4. Fully static — no backend, no database, no tests, no CI. `npm run build` is the only verification gate (it typechecks).

## Commands

- `npm run dev` — http://localhost:3000
- `npx tsc --noEmit` — quick typecheck; there are **no** `lint`/`test` scripts, so don't try `npm run lint`.
- `next-env.d.ts` is generated by Next and gitignored — don't create or edit it manually.

## Content is data-driven from `lib/data.ts`

- All portfolio copy (profile, about, skills, education, projects) lives in `lib/data.ts`. Components only render it — don't hardcode content.
- Adding an entry to `projects` automatically creates its page at `/projects/[slug]` (`generateStaticParams` reads the array; unknown slugs `notFound()`). Project screenshots are PNGs in the `public/` root (some filenames contain spaces, e.g. `/Studio Hive .png`); set `image: "/<file>.png"` to use them.
- Real assets: `public/rafi.jpg`, `public/resume.pdf`.

## Tailwind v4 specifics

- There is no `tailwind.config.*`. Theme tokens are defined in `app/globals.css` under `@theme` — add colors/fonts there.
- The palette is custom `peach-*` and `olive-*` tokens and the scales are incomplete (e.g. no `peach-500`, no `olive-200`). Use these tokens for styling; if a needed shade is missing, add its CSS variable to `@theme` instead of reaching for an arbitrary color.
- Fonts come from `next/font` in `app/layout.tsx` via `--nf-display` / `--nf-body` variables, exposed as `font-display` (Bricolage Grotesque) and `font-sans` (Figtree).

## Conventions

- Path alias `@/*` maps to the repo root — code sits in top-level `app/`, `components/`, `lib/`; there is no `src/`.
- Components are server components by default; `"use client"` only where hooks are used (Navbar and TypeName are the only ones). Default exports.
- Custom keyframes/classes (`.hero-in`, `.type-caret`, `.float-slow`) live in `app/globals.css`. `.hero-in` disables under `prefers-reduced-motion`; the typewriter caret and portrait float intentionally run regardless (site owner request). The typewriter's invisible spacer includes the caret so the caret can never wrap onto a second line — keep the caret mirrored there.
- Icons: `lucide-react` for UI icons, `react-icons/fa6` for brand/social icons — both are deliberately in use.
- Responsive breakpoints: the desktop navbar menu switches at `lg` (not `md`) — the 6 links + resume button overflow the container between `md` and `lg`; keep hamburger below `lg`. Multi-column grids use `sm:grid-cols-2 lg:grid-cols-3` (Skills) or `md:grid-cols-2 lg:grid-cols-3` (Projects); don't jump straight to 3 columns at `md`.
- Home page sections are `<section id="...">` wrappers (via `components/Section.tsx`) that must match the anchor links in `components/Navbar.tsx`; `globals.css` gives them `scroll-margin-top` for the sticky navbar. If you add a section, update both `Navbar.tsx` links and `app/page.tsx` ordering.
